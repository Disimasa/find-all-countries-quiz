# Отчёт: historical-basemaps vs Cliopatria (1100–1500)

**Дата:** 2026-07-04  
**Скрипт:** `scripts/analyze_era_sources_1100_1500.mjs`  
**Сырые данные:** `scripts/.cache/era_sources_report_1100_1500.json`

## 1. Область исследования

### historical-basemaps

- Репозиторий: [aourednik/historical-basemaps](https://github.com/aourednik/historical-basemaps) (GPL-3.0)
- В диапазоне **1100–1500** есть **только 7 снимков** (отдельные GeoJSON), не каждый год:

| Год | Файл | Размер |
|-----|------|--------|
| 1100 | `world_1100.geojson` | 1.02 MB |
| 1200 | `world_1200.geojson` | 1.00 MB |
| 1279 | `world_1279.geojson` | 0.98 MB |
| 1300 | `world_1300.geojson` | 0.97 MB |
| 1400 | `world_1400.geojson` | 1.01 MB |
| 1492 | `world_1492.geojson` | ~2 MB (аномально плотный) |
| 1500 | `world_1500.geojson` | ~1 MB |

### Cliopatria

- Репозиторий: [Seshat-Global-History-Databank/cliopatria](https://github.com/Seshat-Global-History-Databank/cliopatria) (CC BY 4.0)
- Один файл `cliopatria.geojson` (~49 MB), **непрерывная временная ось**
- Для сравнения: политии, у которых `FromYear ≤ Y ≤ ToYear` на каждом из 7 лет-снимков basemaps

## 2. Методология

### Собираемая статистика

| Метрика | basemaps | Cliopatria |
|---------|----------|------------|
| Число features (полигонов) | ✓ | ✓ (активных на год) |
| Уникальные имена (`NAME` / `Name`) | ✓ | ✓ |
| Features без имени | ✓ | — |
| Дубликаты имён (несколько полигонов на имя) | ✓ | ✓ |
| «Культуры / hunter-gatherers» (эвристика) | ✓ | ✓ |
| Русь (по regex имён) | ✓ | ✓ |
| Монголы / улуса (regex) | ✓ | ✓ |
| Политии в bbox Руси 22–50°E, 45–62°N | — | ✓ |
| Иерархия | `SUBJECTO`, `PARTOF`, расхождения | `MemberOf`, `Components` |
| Wikidata | — | ✓ (100% на всех годах) |
| Средняя сложность геометрии (вершин/feature) | ✓ | — |
| `BORDERPRECISION` | ✓ | — |
| Типы (`Type`: POLITY, RELATION…) | — | ✓ |
| Записи «Allegiance…» / скобочные имена | — | ✓ |

### Оценка качества (шкала 1–5, эвристика)

**basemaps:** полнота глобального набора, детализация Руси, иерархия SUBJECTO/PARTOF, доля безымянных полигонов, бонус за 4 улуса (1279+) или княжества (1200).

**Cliopatria:** число политий, Wikidata, детализация Руси, штраф за «дыры» на 1279 и избыток allegiance-записей.

**Пересечение:** Jaccard по fuzzy-совпадению имён (порог 0.6), отдельно по всем политиям и по Руси.

> Оценки — **относительные для выбора эпохи квиза**, не академический вердикт.

## 4. historical-basemaps — по годам

### 1100 (оценка 3.7/5)

| | |
|--|--|
| **Политий** | 139 уникальных, 235 features |
| **Без имени** | 85 features (36%) — «пустые» полигоны |
| **Русь** | Kievan Rus, Mongols, Principality of Polotsk, Prussians |
| **Монголы** | Mongols (ещё не улуса) |
| **Иерархия** | 4 ребра SUBJECTO≠PARTOF — почти плоский датасет |
| **Культуры** | ~16 hunter-gatherer / tribe записей |

**Полнота:** средняя для глобального квиза. **Русь:** один агрегат «Kievan Rus», без дробления на княжества.

---

### 1200 (оценка 4.2/5) — лучший basemaps для Руси

| | |
|--|--|
| **Политий** | 129 |
| **Русь** | Principality of Kyiv, Galicia-Volhynia, Novgorod, Vladimir-Suzdal, **Other Rus Principalities**, Mongol Empire |
| **Монголы** | Mongol Empire (единый полигон, не 4 улуса) |
| **Иерархия** | 5 иерархических связей |

**Полнота:** лучшая **детализация русских княжеств** в basemaps.  
**Минус:** исторически это **до/на пороге** ордынского передела; нет Золотой Орды и четырёх улусов.

---

### 1279 (оценка 4.0/5) — лучший basemaps для монгольского мира

| | |
|--|--|
| **Политий** | 113 (после фильтра культур ~100) |
| **Русь** | Novgorod, Ryazan, Lithuania, Teutonic Knights + **монолит Golden Horde** |
| **Улусы** | Great Khanate, Chagatai, Ilkhanate, Golden Horde — **все 4** |
| **Иерархия** | Novgorod/Ryazan: SUBJECTO=Mongol Empire, отдельные PARTOF |

**Полнота:** оптимален для **глобального квиза «мир при монголах»**.  
**Минус для Руси:** Москва, Тверь, Смоленск, Владимир **внутри** полигона Орды, не кликабельны.

### 1300 (оценка 3.7/5)

| | |
|--|--|

| **Улусы** | те же 4 |

**Vs 1279:** +1 полития (Москва). Имеет смысл только если нужна Москва в том же пайплайне.

---

### 1400 (оценка 3.2/5) — слабый по Руси

| | |
|--|--|
| **Русь** | Novgorod, Poland-Lithuania, Teutonic Knights |
| **Улусы** | только Chagatai + Great Khanate (без Golden Horde / Ilkhanate как отдельных имён) |

**Полнота:** позднее Средневековье, Русь **схлопнута** (Польша-Литва вместо княжеств).

### 1492 (оценка 3.7/5) — аномалия

| | |
|--|--|
| **Политий** | **1307** / 1946 features — в ~10× больше других годов |
| **Причина** | детализация Америки (эпоха «открытий») |
| **Русь** | 6 имён (Novgorod, Muscovy, Lithuania, Teutonic, Golden Horde, Poland-Lithuania) |

**Для квиза:** непригоден как «типичный» глобальный снимок — раздутая выборка, низкое глобальное пересечение с Cliopatria (Jaccard 0.03).

---

### 1500 (оценка 3.7/5)

| | |
|--|--|
| **Русь** | 7 имён (Muscovy, Novgorod, Tver, Pskov, Lithuania, Teutonic, Poland-Lithuania) |
| **Улусы** | 2 (Chagatai, Great Khanate) |

Переход к раннему Новому времени; монгольская тема уже слабеет.

---

### Общие сильные/слабые стороны basemaps

| Сильные | Слабые |
|---------|--------|
| Готовый GeoJSON на год | Только 7 точек времени в 1100–1500 |
| Простая схема `NAME` + `SUBJECTO`/`PARTOF` | 35–55% features без `NAME` |
| 1279: все 4 улуса | Русь после 1237 схлопнута в Орду |
| 1200: максимум княжеств | `BORDERPRECISION` почти везде = 1 (грубые границы) |
| Удобен для Leaflet/MapLibre | GPL-3.0 (спорно для данных) |
| Стабильный размер ~1 MB/год | Нет Wikidata, нет явных дат жизни политии |

## 5. Cliopatria — по годам

### Общие наблюдения

- **Wikidata:** 100% записей на всех годах
- **MemberOf / Components:** развитая иерархия (24–47 связей MemberOf на год)
- **Типы:** в основном `POLITY`, иногда `RELATION` (союзы, персональные унии)
- **Allegiance / скобки:** записи вида `(Allegiance of X to Y)` — полезны для истории, шумны для квиза
- **Средняя площадь полигона:** 250k–640k km² (крупные «ковры»)

### Русь по годам (имена, не bbox)

| Год | Именованная Русь (CL) | Комментарий |
|-----|----------------------|-------------|
| 1100 | 10 (Киев, Новгород, Чернигов, Смоленск, Рязань, Волынь, Ростов-Суздаль…) | **Лучше basemaps** |
| 1200 | 10 (+ Минск) | **Лучше basemaps** |
| **1279** | **4** (Литва, Teutonic, Minsk, **Mongol Empire**) | **Дыра:** нет Новгорода, Рязани, Москвы; один монолит Mongols |
| **1300** | **12** (Москва, Тверь, Псков, Новгород, Смоленск, Владимир-Суздаль, Golden Horde…) | **Резкий скачок** — с 1294 в данных |
| 1400 | 11 (+ союзы Орды с Тимуридами) | Хорошая детализация |
| 1492 | 7 | Меньше имён, но bbox Руси богаче |
| 1500 | 7 | Схоже с 1492 |

### Монгольский блок

| Год | Cliopatria |
|-----|------------|
| 1100–1200 | нет отдельных улусов |
| 1279 | только **Mongol Empire** |
| 1300+ | Yuan, Golden Horde, Chagatai, Ilkhanate (как на basemaps 1279) |

**Вывод:** Cliopatria **хуже basemaps на 1279** по монгольской картине и Руси; **лучше с 1300** по княжествам.

## 6. Пересечение датасетов (одинаковые годы)

### Глобальное совпадение имён (Jaccard)

Низкое везде (**0.13–0.15**), кроме 1492 (**0.03** из-за взрыва числа политий в basemaps).

**Почему низко:**

- Разные соглашения: `France` vs `(Kingdom of France)`, `Aragón` vs `Crown of Aragon`
- basemaps включает культуры/племена, Cliopatria — графства Европы
- Cliopatria дробит Индию/Испанию на династии, basemaps — нет

**Типичные успешные пары:** Byzantine Empire, Khmer Empire, Holy Roman Empire, Fatimid/Almohad, Crown of Castile/Aragon.

### Русь (Jaccard по regex-именам)

| Год | Jaccard | basemaps только | Cliopatria только |
|-----|---------|-----------------|-------------------|
| 1100 | 0.17 | Mongols, Prussians | 8 княжеств (Киев, Новгород, Смоленск…) |
| 1200 | 0.33 | Mongol Empire, Other Rus | Киев, Рязань, Смоленск, Минск… |
| 1279 | 0.29 | **Орда, Новгород, Рязань** | **Mongol Empire**, Минск |
| **1300** | **0.39** | Орда, Новгород, Рязань | Москва, Тверь, Псков, Смоленск… |
| 1400 | 0.17 | Новгород, Польша-Литва | Москва, Тверь, Псков, Орда… |
| 1492 | 0.63 | — | — |
| 1500 | 0.56 | — | — |

**1279:** датасеты **расходятся по модели Руси** — basemaps даёт Новгород/Рязань, Cliopatria в это время видит только «Mongol Empire».

**1300:** лучшее **комбинированное** покрытие — basemaps даёт 4 улуса, Cliopatria добавляет 12 русских имён.

### Оценка качества пересечения (1–5)

| Год | Все политии | Русь |
|-----|-------------|------|
| 1100 | 1.8 | 1.8 |
| 1200 | 1.8 | 2.2 |
| 1279 | 1.8 | 2.6 |
| 1300 | 1.8 | **2.3** |
| 1400 | 1.8 | 1.8 |
| 1492 | 1.6 | **3.3** |
| 1500 | 1.8 | **3.1** |

Пересечение **не высокое** — датасеты дополняют друг друга, а не дублируют.

## 7. Рекомендации для гео-квиза

### Цель: «потыкать русские княжества»

| Приоритет | Год | Источник | Почему |
|-----------|-----|----------|--------|
| 1 | **1200** | basemaps | 6 русских полигонов, максимум в basemaps |
| 2 | **1300** | **Cliopatria** или basemaps+CL | 12 имён Руси в CL; basemaps + Москва |
| 3 | 1100 | Cliopatria | 10 княжеств vs 1 «Kievan Rus» в basemaps |
| ✗ | **1279** | — | Худший компромисс для Руси (2–5 полигонов) |

### Цель: «4 улуса + мир XIII в.»

| Приоритет | Год | Источник |
|-----------|-----|----------|
| 1 | **1279** | basemaps (единственный файл с `world_1279`) |
| 2 | 1300 | basemaps (те же улуса + Москва) |

### Цель: один источник, лицензия CC BY

- **Cliopatria**, но эпоху сдвинуть на **≥1300**, не 1279.

### Гибрид (если нужны и улуса, и княжества)

```
basemaps world_1300  →  глобаль + 4 улуса
Cliopatria @1300      →  русские княжества (или выборочный merge)
```
